# Tic-Tac-Toe (JavaScript)

A two-player tic-tac-toe game that runs in the browser — plain HTML, CSS, and
JavaScript, no build step and no dependencies.

**Tech stack:** HTML, CSS, vanilla JavaScript

## Why this project

A friendly introduction to the DOM and event-driven programming: build a grid,
respond to clicks, track game state, and decide who wins. Everything happens in
the browser with no libraries to install.

## How to run

Open `index.html` in any modern web browser. That's it.
